# 0.6.0 ATM10 后台重编码核验

> NeoForge 来源版历史记录：本文的性能数据及验证数量不代表 Fabric 1.21.1 移植版，Fabric 版尚未通过 ATM10 验证。

日期：2026-11-10。ATM10 8.5 隔离正式服务端，Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21.0.10。使用已通过本地验证的原始 0.6.0 JAR，生产代码及 JAR 在本轮未改变。

## 正确性

三个独立服务端启动完成。共 49,078 个方块、1,548,745 个注册状态、221 个命名空间，实际通过先保存完整 NBT、后台重编码、关闭和重开持久化路径。

合成区块 12,290 个；实际持久化的完整区段引用记录 2,486 个、状态共享记录 2,828 个。190 组独立重开，190 组独立区块改写检查，完整 NBT 比较通过。

另生成 64+16 个新主世界 FULL 区块，在后续启动中逐位置比较全部方块状态哈希，最终重开检查 80 块。真实世界哈希包含注册名及全部方块属性，不覆盖实体、方块实体、生物群系和光照；合成 NBT 测试另作完整值比较。停服允许取消待优化任务，未压缩完的普通记录仍可重开。

## 保存对照

六个新世界、六个独立 JVM，按原版 / 0.5.2 / 0.6.0 / 0.6.0 / 0.5.2 / 原版串行执行。相同种子 512060，预热 8 块后每 tick 获取一个目标 FULL 区块，共 256 块，存在额外邻居生成。均为 -Xms4G -Xmx10G、G1、sync-chunk-writes=true、视距和模拟距离 3。除 ChunkSqueeze 外，六轮模组 ID/版本集合完全相同。

生成结束后立即 saveEverything(true,true,true)，明确等待全部前台 I/O；随后 0.6.0 等待后台、再次 flush，再等待这次 flush 可能产生的后台任务。四段分别计时。计时不含启动、预热和后续哈希；外部进程内存计数每 0.5 秒一次，未在这些性能进程中附加 JFR 或强制 GC。

0.6.0 前台完整保存较 0.5.2 变化 -38.3%，为原版的 1.24 倍。后台最终完成的总耗时必须同时看；不能仅以前台返回时间宣称计算量减少。

每后端仅两次进程运行，有 JVM 预热、生成与模组行为波动。生成阶段包含 tick 间隔、邻居生成和异步工作，不等同纯地形算法耗时；这些结果不能外推长期多人服 TPS。
